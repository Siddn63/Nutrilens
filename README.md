# Nutrilens

Nutrilens is a food and nutrition web application that helps users search products, check nutritional information, and manage their personal dietary preferences.

## Features

- 🔍 Search food products
- 📷 Scan/upload product barcodes
- 🥗 View nutritional information
- 👤 User login and signup
- 🧑‍⚕️ Manage allergies and preconditions
- 🥦 Veg / Non-Veg preferences
- 📊 Product and ingredient information

## Tech Stack

- React
- Vite
- Tailwind CSS
- FastAPI
- MongoDB

## Deployment

The frontend and backend are deployed separately and connected through APIs.
